# BEKHAN OS

Интерактивный прототип персонального центра управления исполнительного директора. Статический сайт на HTML, CSS и JavaScript, без сервера, учётных записей и подключений к внешним источникам данных.

**Все записи и показатели — демонстрационные. Это не корпоративная отчётность. Не используйте публичный прототип для реальных персональных и финансовых данных.**

## Что можно проверить

- Главная: план и факт дохода, приоритеты, задачи дня и связанные цели.
- Финансы: переключение октября/ноября, поступления и расходы, остаток с начальным балансом, отдельный прогноз и сценарий дополнительных продаж.
- Франшиза: пять этапов воронки, редактирование сделок, дата следующего контакта, история, источники, причины потери и предварительный анализ этапов.
- Бронь Сервис: фильтры регионов, выручка и прибыль, недельная динамика, выявление отклонений по правилам, создание задачи по точке.
- Личный бренд: контент-план, статусы, показатели примера и связь материала с карточками CRM.
- Цели: накопления, выделенный бюджет, ориентиры сроков и этапы проектов.
- Тренировки: пример А/Б, журнал упражнений, график рабочего веса, подсчёт уникальных тренировочных дней.
- Задачи: сроки, приоритеты, исполнители, редактирование и завершение.
- Поиск по разделам и записям, уведомления, экспорт JSON, сброс демоданных.

Данные сохраняются только в localStorage текущего браузера. Синхронизации между устройствами нет. При запрете хранилища приложение сообщает об этом и работает в памяти до перезагрузки.

## Расчёты и допущения

- Дата демосценария: **12 ноября 2026**. Просрочки и план недели привязаны к этой дате.
- Получено за ноябрь: **428 000 ₽**, расходы **135 500 ₽**. За октябрь: **540 000 ₽**, расходы **184 000 ₽**.
- Начальный денежный остаток перед октябрём: **320 000 ₽**. Остаток на текущую дату ноября: **968 500 ₽**.
- Базовый прогноз: факт ноября + ожидаемые **252 000 ₽**. За дополнительную продажу в симуляторе: **120 000 ₽ личного вознаграждения**, не выручки компании. Прогноз не меняет полученные деньги.
- План продаж: 3 оплаты в демонстрационном месяце. Бюджет покупателя не является выручкой и не включается в личный доход.
- Сигнал по точке: рентабельность ниже условного ориентира 24% более чем на 5 п. п. или три последовательных снижения недельной выручки. Причины проблем не считаются установленными автоматически.
- Воронка анализа — срез текущих карточек с допущением прохождения предыдущих этапов; это не историческая конверсия по событиям.
- Цели имеют собственные накопления/бюджеты. Связи списаний с финансами нет. Цель по доходу получает факт из финансов.
- «Сводка» работает по фиксированным правилам. Подключённого ИИ нет.
- Показатели Instagram — пример; новых просмотров или реальных обращений сайт не получает.

## Запуск и публикация

Достаточно обычного статического сервера в корне проекта, например `python -m http.server 8000`. Зависимости и сборка не нужны. Дополнительный шрифт загружается из Google Fonts; при недоступности используется системный.

GitHub Pages публикует ветку `main`, папку `/`. Файл `.nojekyll` отключает обработку Jekyll. Все ресурсы подключены относительными путями, разделы используют hash-навигацию и открываются напрямую после перезагрузки.

Следующий этап после согласования интерфейса: роли и авторизация, общая база с резервными копиями, согласованные источники данных, интеграции и только затем ИИ-аналитика. Эти функции намеренно не имитируются как подключённые.
